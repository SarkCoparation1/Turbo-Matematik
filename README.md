# Turbo Matematik

Bu turbowarp eklentisi gelişmiş özelliklere sahiptir.

## Özellikleri:
1. Üçlü 4 işlem yapma
2. Kare ve küp alabilme

## Nasıl kullanılır?
1. "https://turbowarp.org/" sitesini açın
2. Eklentiler -> Custom extension seçeneğine gidin
3. "https://github.com/SarkCoparation1/Turbo-Matematik/" linkini kopyalayıp URL bölümüne yapıştırın ve yükle deyin.
4. Artık kullanıma hazır.
